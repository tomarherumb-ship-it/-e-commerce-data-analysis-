# 🛒 E-Commerce Data Analysis Project

## 📌 Project Overview
This project focuses on analyzing e-commerce sales data to understand sales performance, product trends, customer behavior, and business performance. It uses Excel, Python, SQL, and Power BI to transform raw data into meaningful business insights.

## 🛠️ Tools & Technologies
- **Microsoft Excel:** Data cleaning, data analysis, PivotTables, and charts.
- **Python:** Data cleaning, preprocessing, and analysis using Pandas.
- **SQL (MySQL):** Data querying, aggregation, and business analysis.
- **Power BI:** Interactive dashboard creation and data visualization.

## 📂 Project Structure
- **Excel/** — Raw data, cleaned data, and Excel analysis.
- **Python/** — Python scripts for data cleaning and preprocessing.
- **SQL/** — SQL queries for sales analysis and business insights.
- **PowerBI/** — Power BI dashboard and visualizations.

## 🔄 Project Workflow
1. **Data Preparation:** Examined the raw e-commerce dataset and identified data quality issues.
2. **Data Cleaning:** Used Excel and Python to handle missing values, remove duplicates, and prepare data for analysis.
3. **SQL Analysis:** Used MySQL queries to analyze sales, products, customers, and regional performance.
4. **Dashboard Development:** Created a Power BI dashboard to visualize key metrics and trends.
5. **Business Insights:** Used the analysis to identify sales patterns and support data-driven decisions.

## 📊 Key Business Questions
- What is the total revenue generated?
- Which products generate the highest sales?
- Which regions perform best?
- How do sales change over time?
- Which customers or customer segments contribute most to sales?
- What business opportunities can be identified from the data?
